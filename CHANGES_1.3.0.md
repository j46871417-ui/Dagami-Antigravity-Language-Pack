# 1.3.0 — совместимость с актуальными Antigravity

- Исправлен поиск Antigravity IDE 2.6.0: поддерживается новое встроенное расширение `agy` / `google-antigravity`, сохранена старая структура.
- Исправлен путь `argv.json` в Windows. Пользовательские настройки IDE и каталог расширений учитываются отдельно.
- Перевод динамической боковой панели подключается к browser bundle IDE и меняет отображаемый текст. Программные значения в bundle и Node extension host новой IDE сохраняются.
- Сохранены установка, смена языка и побайтовый откат Desktop 2.28.2.
- В GUI и командной строке появился отдельный выбор Antigravity CLI. Для проверенного Windows x64 CLI 1.4.10 добавлен русский перевод 20 известных описаний и служебных строк справки.
- CLI-пакет частичный: он не переводит весь TUI, команды, ответы модели и пользовательский код. Другие языки CLI и macOS/Linux-бинарники CLI пока не поддерживаются. Непроверенная сборка отклоняется по SHA-256 до изменения файла. Сохранены размер файла, код, указатели и форматные строки. Откат возвращает ровно исходный бинарник, включая уже существовавшие сторонние изменения.
- Добавлены регрессионные тесты и `tools/verify_installed_compatibility.py`: проверка на копиях установленных файлов без чтения аккаунтов и изменения работающих приложений.

## Проверка и ограничения

Целевые версии сверены с [официальным changelog Google](https://antigravity.google/docs/changelog): Desktop 2.28.2, IDE 2.6.0 и CLI 1.4.10. Проверка структуры/установки/отката на копиях не заменяет визуальную приёмку в работающих приложениях.

CLI — нативный Go executable; универсальный поиск/замена слов в нём небезопасен. Допускаются только известные хеши и однозначные строки в read-only секции PE. Добавление новой версии требует отдельной проверки оригинального бинарника и запуска его копии. Неизвестные версии не разрешаются автоматически. Существующая системная подпись изменённого Windows CLI перестаёт соответствовать файлу; исходный файл хранится для восстановления. Изменение подписанного macOS bundle по-прежнему запрещено.

Перед применением сохраните работу и закройте выбранное приложение. Проверочный инструмент сам не закрывает установленные приложения и не пишет в их каталоги.
