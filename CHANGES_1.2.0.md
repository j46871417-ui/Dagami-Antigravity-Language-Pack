# Dagami Language Pack 1.2.0

## Что нового

- Компактный нативный GUI, чёткие кнопки и подсветка при наведении.
- Новый вид флажков; лишняя полоса прокрутки убрана.
- Явный выбор языка; по умолчанию — русский.
- Новая иконка A/Я в окне, EXE, .app и меню Linux.
- Сборки Windows x64, Linux x64/ARM64 и macOS Intel/Apple Silicon.
- Правки путей, JSONC, ASAR, копий и отката по итогам аудитов.
- Перевод мыслей хранит вид блоков, ссылки, списки и код.
- Проверка версий и загрузка пакета для своей ОС и CPU.

## Как запустить

- Windows: распакуйте весь ZIP, запустите `AntigravityLocalizer.exe`.
  Папку `_internal` держите рядом; один EXE переносить нельзя.
- Linux: распакуйте TAR.GZ и запустите `DagamiLanguagePack`.
  Для GUI нужен X11 или XWayland. Есть `install_desktop.py` для меню.
- macOS 15+: распакуйте TAR.GZ и откройте `DagamiLanguagePack.app`.
  Выберите Intel (x64) или Apple Silicon (arm64).

Python уже входит в сборки. Для запуска кода нужен Python 3.10+ и Tk.
Перед сменой языка сохраните работу и закройте Antigravity.
После смены версии утилиты снова нажмите «Установить язык».
Для возврата есть кнопка English и копии исходных файлов.
При смене версии утилиты заменяйте весь пакет вручную.

## Проверки и рамки

Пять сборок прошли в GitHub Actions на своих ОС и CPU.
В каждой прошёл запуск `--verify-bundle` и контроль ресурсов.
Тип файла, CPU, SHA-256, права запуска и состав пакетов сверены.
Это не проверка GUI или записи языка в реальную IDE на всех ОС.
Повторный запуск Windows EXE из CI на этом ПК не дал кода выхода;
его локальный успех не подтверждён, хотя проверка в CI прошла.

На macOS утилита имеет подпись ad hoc, без Developer ID и нотариуса Apple.
Правка IDE с подписью или ASAR integrity пока даёт отказ до записи.
Полной работы с такой IDE этот порт пока не даёт.

Сетевой перевод мыслей по умолчанию выключен. Если его включить,
текст мысли уйдёт в Google. Код, URL и поля ввода из него исключены.

К сборкам приложены SHA-256 и отчёты CI. Код есть по тегу `v1.2.0`.
