# 1.2.0: что сделано

Сборка пока локальная. На GitHub ещё не выложена.

## Размер

- Из EXE убраны старая копия Antigravity и старый веб-код.
- В Windows ZIP нет второй копии данных, уже вшитых в EXE.
- Python и Tk входят в EXE для запуска без их установки.

## Вид перевода

- Заголовки, списки, таблицы, ссылки и код сохраняют свой вид.
- Перевод идёт в копии блока. Исходные узлы не меняются.
- Код, поля ввода и адреса ссылок не уходят в сервис перевода.
- Кнопка копии и ссылки вызывают прежние действия.
- EN возвращает исходный текст и стили.
- При новом тексте старый перевод скрыт. Отмена не даёт позднему ответу
  подменить свежий текст.
- В сети идут не более двух запросов разом. Кеш имеет лимит.

## Новые версии

- В окне есть кнопка «Обновления».
- Проверка GitHub идёт при запуске и раз в 6 часов. Её можно выключить.
- Скачать и установить — лишь по кнопке. Сами эти шаги не начнутся.
- Windows EXE сверяет SHA-256, имя продукта и версию файла.
- Старый EXE сохраняется. При сбое записи есть откат.
- Помощник ждёт выхода старой копии, без kill.
- В режиме исходников доступна проверка и загрузка пакета для вашей ОС.
  Замена файлов в этом режиме — вручную.
- Сборка EXE в ZIP и отдельный EXE теперь идут из одного файла.
  В CI и на ПК один путь сборки.

После первого перехода замените EXE вручную. Затем нажмите «Установить язык»,
чтобы новый движок вошёл в Antigravity. Открытый Antigravity сначала закройте.

## Пределы проверки

Проверки выполнены на Windows. Linux/macOS собраны как архивы исходников;
запуск на этих ОС не проверен. Установка EXE в папку без прав записи
не идёт: перенесите утилиту в свою папку либо замените файл вручную.
