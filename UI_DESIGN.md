# Вид GUI — 17.10.2026

## Основа

Стиль взят из Dagami Agent Proxy:
https://github.com/j46871417-ui/Dagami-Agent-Proxy/blob/main/FluentUi.cs

Фон #F3F5F8, карточки #FFFFFF, текст #1D232C,
серый текст #5B6574, акцент #005FB8, боковая панель #EBF0F6.
Шрифт Segoe UI, отступы 8/12/16/24, радиус карточек 10.
Поля ввода имеют более тёмную рамку #8190A2 для явных границ.

## Что сделано

- Нативный Tk GUI с боковой панелью и белыми карточками.
- Шесть языков видны сразу; русский выбран по умолчанию.
- Язык обязателен: пустое или чужое значение не даёт начать запись.
- Кнопка явно называет язык, который будет применён.
- Выбор и поля заблокированы на время записи.
- Журнал и строка хода работы видны на главном экране.
- При малой высоте есть полоса прокрутки; журнал имеет свою полосу.
- Нет ярких кнопок доната и эмодзи вместо значков.
- Русский выбран по коду ru, а не по порядку папок.

## Проверки и рамки

Применён ui-ux-pro-max и прочтён better-interface.
У better-interface нет файла review-format.md и шести дочерних скиллов.
По ним нет полного ревью: accessibility, layout, writing, typography,
colors, UI — Not reviewed этими скиллами. Их правила не воссозданы.

По ui-ux-pro-max учтены нативные поля, фокус, простой текст,
состояние с подписью, единый акцент и доступ к полям с клавиатуры.
Статический контраст на белом: акцент 6.31:1, серый текст 5.90:1,
рамка поля 3.26:1. Это расчёт токенов, не замер снимка окна.

## Компактный вид

Базовый размер снижен с 1040×790 до 900×650 при масштабе 100%.
Минимум — 840×600. Боковая панель — 156 вместо 180.
Убрана лишняя строка над заголовком. Поля, кнопки и карточки
стали плотнее; размер основного текста сохранён.
Серый текст и рамки стали темнее. Пустая полоса хода работы скрыта.
Режим DPI Windows включается до создания окна Tk; размер окна
учитывает DPI экрана. Это снижает риск размытия текста при масштабе ОС.
Русский по умолчанию и явный выбор языка сохранены.

## Кнопки и наведение

У кнопок видимая рамка и лёгкая заливка даже без наведения.
При наведении фон становится голубым, рамка — синей.
При нажатии цвет темнее. Главная кнопка сохраняет белый текст.
Выбранный язык также получает подсветку при наведении.
Фокус с клавиатуры и вид выключенных кнопок сохранены.
Размер кнопок не меняется между состояниями.
