## Сбой входа в EXE на этом ПК

Первый EXE собран в режиме onefile. Его загрузчик дал ошибку:
`Could not create temporary directory!`
Она идёт до входа в Python, при создании папки в `%TEMP%`.
По этому логу нельзя считать сам GUI сломанным.
Обычная запись Python в TEMP здесь проходит; сбой есть
при создании папки загрузчиком. Сам лог не даёт код отказа ОС;
связь с ACL в этом сеансе остаётся выводом, а не прямым фактом.
Права TEMP и правила ОС не меняли.

Вариант с файлами в одной папке собран без этого шага.
Его команда `--verify-bundle` дала код 0.
В исходник добавлен режим `python build_release.py --onedir`.
Для Inno Setup с этим режимом нужен флаг `/DFolderBuild`.
Такую сборку надо переносить целой папкой, вместе с `_internal`.
Смена одного EXE через модуль обновлений для неё отключена:
доступна загрузка, весь пакет надо менять вручную.

Режим onefile сохранён. На этом ПК его запуск не подтверждён.
