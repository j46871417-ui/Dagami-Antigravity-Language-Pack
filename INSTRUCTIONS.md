# Как запустить

## Windows

1. Распакуйте весь ZIP в свою папку.
2. Закройте Antigravity, сохранив работу.
3. Запустите EXE, выберите язык и нужные пути.
4. Нажмите «Установить язык» и откройте Antigravity.
5. Для отката нажмите кнопку возврата к English.

Для сборки из папки всегда меняйте весь пакет, включая `_internal`.
После замены снова установите язык: это обновит движок внутри Antigravity.
GUI и CLI используют одно ядро. Не переносите один EXE из сборки из папки.

### Актуальные версии и CLI

В исходниках 1.3.0 исправлена IDE 2.6.0 с расширением `agy`, добавлен
перевод её динамической панели; проверены операции на копии Desktop 2.28.2.
В окне установки отдельно отмечаются Desktop, IDE и Antigravity CLI.

CLI-пакет для Windows x64 1.4.10 переводит 20 служебных строк справки;
полной локализации интерактивного TUI нет. Другие версии, архитектуры и
языки CLI не разрешаются автоматически. Имена команд и их аргументы,
ответы модели и пользовательский код не изменяются. Изменённый EXE не
сохраняет действительность исходной цифровой подписи; есть точный откат.

Для одной цели используйте явный путь — остальные приложения не затрагиваются:

~~~powershell
python language_pack.py --lang ru --ide-path "C:\path\Antigravity IDE"
python language_pack.py --lang ru --cli-path "C:\path\agy.exe"
python language_pack.py --restore --cli-path "C:\path\agy.exe"
~~~

Флаг `--cli` открывает меню установщика; `--cli-path` выбирает приложение CLI.
Перед установкой закройте именно выбранное приложение. Если CLI уже изменён
другой программой и его хеш не поддерживается, исходник не затирается.

## GitHub

Откройте «Обновления». Проверка идёт сама при запуске и раз в 6 часов.
Можно её выключить или включить поиск тестовых версий.
В режиме onefile смена версии идёт лишь по кнопке.
В сборке из папки доступна загрузка; весь пакет меняется вручную.
Старый EXE будет сохранён; при сбое записи есть откат.
Во время установки языка обновить утилиту нельзя.

В папке без прав записи замена не идёт. Перенесите утилиту в свою папку.
Путь старой копии и итог лежат в:
%LOCALAPPDATA%/DagamiAntigravityLanguagePack/updates/last-result.json

## Linux и macOS

В нативном пакете Python уже есть. Распакуйте TAR.GZ.
На Linux запустите `DagamiLanguagePack`; для GUI нужен X11 или XWayland.
На macOS 15+ откройте `DagamiLanguagePack.app`. Выберите пакет для своего CPU.
Подпись утилиты ad hoc, без Developer ID и нотариуса Apple.

Для запуска кода нужны Python 3.10+ и Tk. Выполните:

~~~sh
./dagami-ag-localizer.sh --list
./dagami-ag-localizer.sh --lang ru
./dagami-ag-localizer.sh --gui
./dagami-ag-localizer.sh --check-update
./dagami-ag-localizer.sh --download-update
~~~

При нужде дайте файлу .sh право запуска через chmod +x.
Сборки и `--verify-bundle` прошли в CI; GUI и запись в IDE пока не проверены.
В режиме исходников новая версия скачивается, а замена файлов — вручную.

## Вид перевода

Кнопки RU/EN у мысли меняют язык, «Авто» включает перевод новых мыслей.
Сетевой перевод по умолчанию выключен.
В 1.3.1 исправлен автоматический режим. После обновления EXE снова нажмите
«Установить язык», перезапустите выбранный Antigravity и включите «Авто» у
любого блока мыслей. Режим применяется ко всем блокам окна, включая новые.
Если хранилище браузера запрещено, выбор действует до закрытия окна.
Код, ссылки и списки не должны терять свой вид.
EN вернёт исходный блок. При новом тексте старый перевод отменяется.

## Сборка с правками

Нужны Python 3.10+, Node и пакеты из requirements.txt.

~~~sh
python build_release.py --onedir
~~~

Это даёт папку с нативным GUI для вашей ОС. Для пакета есть `--package`.
Для одного EXE на Windows есть `--onefile`; в выпуске его нет.
Для сборки нужны Python 3.12+, Node и Tk. Сборка идёт на целевой ОС.
macOS с подписью: отказ до записи, пока нет режима новой подписи.
Рамки платформ и форматы сборок описаны в PORTS.md.
