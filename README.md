# Google Antigravity Localizer (Русификатор)

Автономный русификатор для приложений **Google Antigravity**:
- **Antigravity 2.0 (Desktop Electron App)**: полный перевод динамического веб-интерфейса, настроек, панелей, вкладок, меню окна и трея.
- **Antigravity IDE**: полная русификация каркаса редактора (VS Code framework, меню, окна, настройки на 15 000+ строк) и встроенного чата агента.

---

## Возможности

- **Автоматическое обнаружение**: сам находит установленные версии Antigravity в стандартных путях Windows.
- **Выбор своего пути**: можно вручную указать папки приложений, если они установлены в нестандартное место.
- **Тихое закрытие процессов**: перед прошивкой тихо и безопасно завершает процессы Antigravity без мелькания консольных окон.
- **Резервное копирование и откат**: автоматически создаёт резервные копии оригинальных файлов (`*.bak.original`) и позволяет в 1 клик вернуть всё как было.
- **Полный перевод настроек**: переведены все параметры (Settings), правила безопасности, права доступа, горячие клавиши и описания опций.
- **Графический интерфейс и CLI**: удобное окно на русском языке либо работа через аргументы командной строки.

## Быстрый запуск (для пользователей)

1. Скачайте актуальный `AntigravityLocalizer.exe` из раздела [Releases](https://github.com/j46871417-ui/-Antigravity/releases/tag/0.0.1).
2. Запустите файл (права администратора не требуются, если приложение установлено в AppData).
3. Нажмите **«Установить русификатор»**.
4. Запустите Google Antigravity — интерфейс будет полностью на русском языке.

> **Как вернуть английский язык**: запустите программу и нажмите **«Откатить (восстановить оригинал)»**.

## Параметры командной строки (CLI)

```bash
# Установка в тихом консольном режиме (по путям по умолчанию):
AntigravityLocalizer.exe --cli --install

# Откат к оригиналу через консоль:
AntigravityLocalizer.exe --cli --restore

# Указание пользовательских путей:
AntigravityLocalizer.exe --cli --install --ide-path "D:\Apps\Antigravity IDE" --desktop-path "D:\Apps\Antigravity"
```

## Сборка из исходников

Требуется **Python 3.10+**:

```bash
# 1. Клонировать репозиторий:
git clone https://github.com/your-username/antigravity-localizer.git
cd antigravity-localizer

# 2. Установить зависимости:
pip install -r requirements.txt

# 3. Собрать исполняемый файл:
build_exe.bat
```

После завершения готовый `AntigravityLocalizer.exe` появится в корневой папке.

## Структура проекта

- `antigravity_localizer.py` — основной файл приложения (GUI на Tkinter + логика патчинга + CLI).
- `translations/dom_translator.js` — динамический движок перевода DOM для Antigravity Desktop (включая перехватчики прототипов, Shadow DOM, словарь настроек).
- `translations/` — словари переводов интерфейса и настроек.
- `assets/nls.messages.ru.json` — перевод каркаса VS Code (15 000+ строк) для Antigravity IDE.
- `patch_desktop.py` — отдельный скрипт для прямой прошивки Desktop (`app.asar`).
- `patch_ide.py` — отдельный скрипт для прошивки IDE.
- `build_exe.bat` — скрипт автоматической компиляции PyInstaller в один автономный `.exe`.
