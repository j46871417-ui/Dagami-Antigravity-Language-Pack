## ⚡ Быстрая установка (1 команда в PowerShell)

Самый быстрый и безопасный способ установки. **Не требует прав администратора, не вызывает ложных срабатываний антивирусов.**

Откройте консоль **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/j46871417-ui/Antigravity-Localizer/main/install.ps1 | iex
```

> **Для отката к оригинальной версии от Google** запустите:
> ```powershell
> irm https://raw.githubusercontent.com/j46871417-ui/Antigravity-Localizer/main/install.ps1 | iex -Uninstall
> ```

## 🚀 Альтернативные способы установки

### Вариант 1: Запуск через `install.bat` (в один клик)
1. Скачайте архив репозитория (кнопка **Code → Download ZIP**).
2. Распакуйте в любую папку и запустите `install.bat`.
3. Скрипт автоматически создаст резервную копию оригинала и установит русификатор.

### Вариант 2: Графический установщик (`AntigravityLocalizer.exe`)
Для тех, кто предпочитает классическое окно с кнопками:
1. Скачайте `AntigravityLocalizer.exe` из [Releases](https://github.com/j46871417-ui/Antigravity-Localizer/releases/tag/0.0.1).
2. Запустите и нажмите **«Установить русификатор»**.
3. Интерфейс Antigravity станет полностью на русском языке.

## 🛡️ Почему PowerShell 100% чист от антивирусов?

| Метод | Ложные срабатывания Windows Defender | Причина |
|---|:---:|---|
| **PowerShell (`install.ps1`)** | **0 (Абсолютно чист)** | Открытый текст сценария, стандартные системные вызовы Windows без бинарных дропперов |
| **`.bat` файл (`install.bat`)** | **0 (Абсолютно чист)** | Прозрачный командный файл Windows |
| **PyInstaller `.exe`** | Возможны эвристические предупреждения (`Wacatac`, `Heur.Boring`) | PyInstaller упаковывает Python и библиотеки во временный распаковщик (`%TEMP%`), на что агрессивно реагируют эвристические сканеры антивирусов |

> 💡 **Рекомендация**: Используйте команду PowerShell (`irm ... | iex`) — это официальный стандарт дистрибуции инструментов на Windows (как scoop, winget или oh-my-posh).

## 🔒 Безопасность и сохранность данных

- **Проекты и сессии**: ваши чаты, история диалогов, настройки рабочих пространств и API-ключи остаются нетронутыми.
- **Резервная копия**: перед внесением изменений создаётся файл `app.asar.original_backup`.
- **Без модификации исходного кода пользователя**: правила фильтрации исключают теги `<pre>`, `<code>`, классы `.token`, `.prism`, редакторы Monaco и терминалы XTerm. Ваш код никогда не подвергнется ошибочному переводу.

## 📁 Структура проекта

```
├── install.ps1                 # Основной скрипт установки через PowerShell (0 ложных детектов)

├── patch_desktop.py            # CLI-утилита для прошивки Electron ядра Desktop
├── patch_ide.py                # CLI-утилита для прошивки расширения IDE
├── resources/
│   ├── app.asar                # Подготовленное локализованное ядро Electron

├── translations/
│   ├── dom_translator.js       # Движок локализации DOM в реальном времени
│   ├── desktop_strings.json    # Строки системного меню и трея
│   └── ide_strings.json        # Строки команд и меню для IDE
└── assets/
    └── nls.messages.ru.json    # 15 000+ строк перевода ядра IDE
```
